### classify (MUST)

1. `!is_file` → `Missing`
2. `read_limited` + `sha256_hex`
3. hash == expected → `Identical`
4. `content_is_managed` → `Apply`
5. else → `Customized`

### plan_update (MUST)

- Filter: `appliesTo` contém `*` **ou** intersecta `target.expanded_ids()`; sem target → todos
- Sort `items` por `path`; `counts` coerentes; `mode: "dry-run"`; `schemaVersion: 1`
- Sem timestamps; **zero** mutações FS

### format_human

Incluir `mode: dry-run (zero mutations)`; secção `customized:` se count > 0; en-US; sem corpo de ficheiro.
