### Fluxo

| Condição | Resultado |
|----------|-----------|
| `!dry_run` | `CoreError::internal("dare update apply is not implemented; use --dry-run (see microplano 022)")` → exit **1** |
| root None | `invalid_input("project root not found")` → exit **4** |
| target inválido / semver | `invalid --target harness:` → exit **4** |
| dry-run OK | human/JSON; envelope `ok:true`; exit **0** |

- Root: `dare_project::find_project_root`
- `cli_version = env!("CARGO_PKG_VERSION")`
- JSON: `data` = UpdatePlan (`schemaVersion` 1, `mode` `dry-run`)
