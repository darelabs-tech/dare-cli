## `--json` data (T-28)

```json
{ "format": "mermaid", "dag": "<rel>", "outputPath": null, "body": "..." }
```

`body` é `null` se escrito em ficheiro via `-o`.

## Edge cases

- Sem project root → exit 4
- DAG missing → 3
- YAML parse fail → 4
- Ciclo → 4, mensagem en-US contém `cycle` (sem dump de prompts)
- `-o` fora do jail → 4
- Sem `-o`: **zero** writes em DAG/state
- State ausente/corrupt → continua com PENDING visuals (soft-fail)
