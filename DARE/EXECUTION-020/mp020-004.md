## Fluxo CLI

1. `dare_project::find_project_root(cwd)` → None ⇒ InvalidInput exit 4
2. `ProjectRoot::new`
3. Resolve `DARE/dare-dag.yaml` ou `--dag` (rel/abs sob jail)
4. `dare_dag::validate_path`
5. Print human / JSON (`envelope.ok = report.ok`)
6. Exit 0 se `report.ok` else **1** (não `write_error` para falha de regras)
7. NotFound=3; Config parse=4; Io=5 via `write_error`
