## Regras MUST

| code | severity | Notas |
|------|----------|-------|
| `invalid_id` | error | kebab `^[a-z0-9]+(-[a-z0-9]+)*$` |
| `duplicate_id` | error | V21 |
| `missing_dependency` / `self_dependency` | error | |
| `cycle` | error | path rotacionado ao menor id; fecha com start |
| `empty_title` | error | trim empty |
| `invalid_complexity` | error | só `LOW`/`MED`/`HIGH` |
| `missing_prompt_or_spec` | error | V21 only |
| `missing_spec_file` | warning | base `{root}/DARE/` + spec_file |
| `invalid_limits` | warning | algum limit == 0 |

- Legacy: **não** aplicar prompt/spec
- Sort: severity → code → taskId → message
- `ok = errorCount==0 && (!strict || warningCount==0)`
- Messages ≤200 chars; **nunca** corpo de `subtask_prompt`
- Zero writes
