## resolve_driver (MUST)

```text
mock | noop → MockDriver
codex → CodexDriver::from_env()?
claude → ClaudeDriver::from_env()?
cursor → CursorDriver::from_env()?
antigravity → AntigravityDriver::from_env()?
other → Err InvalidInput "driver not implemented: {id}"
```

Case-sensitive lowercase only (`Claude` → 4).

## Smokes (MUST)

| Caso | Expect |
|------|--------|
| Fake success override + `DARE_AGENT_SKIP_RALPH` + `--driver codex` (ou claude) | exit 0 |
| Missing exe override | exit **1**, msg contains `executable not found` |
| `--driver not-a-driver` | exit **4** |
| Guard evil file + `--driver mock` | exit **6** (regressão 034) |
