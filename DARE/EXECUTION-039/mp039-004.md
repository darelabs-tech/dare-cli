## Invocação

```text
dare migrate --to <stack> [--check] [-d|--dir <path>] [--ai] [--provider <id>] [--json] [--no-color]
```

| Flag | Regras |
|------|--------|
| `--to` | obrigatório; allowlist via domínio |
| `--check` | zero writes |
| `-d/--dir` | ProjectRoot; NotFound → exit 3 |
| `--ai` | soft-fail enrich pós-write |
| `--provider` | só com `--ai`; default `codex` |

## Exit codes

| Situação | Code |
|----------|------|
| OK | 0 |
| Usage (ex. falta `--to` clap) | 2 |
| NotFound dir | 3 |
| InvalidInput (target/reverse/path) | 4 |

## AI soft-fail (CLI only)

Após write OK: ler `MIGRATION.md` → enrich → `inject_sections` com markers `MIGRATE_ENRICHABLE` / AGENT sections; falha de provider → **exit 0** + warning; não corromper `migration-facts.json`.

## Edge cases

| Caso | Resultado |
|------|-----------|
| `--to Not-A-Stack` | exit 4 |
| sem IDEIA | exit 4, msg `dare reverse` |
| `--ai` provider fail | exit 0 + warning |
| `--json` | envelope JSON do report |
