## Contratos CLI

```rust
Design {
    /// Feature/product description (omit with --interactive).
    description: Vec<String>, // join with " "
    #[arg(long)]
    interactive: bool,
}
```

### Regras

| Condição | Erro |
|----------|------|
| `interactive && !description.is_empty()` | Usage: `cannot combine --interactive with description` → exit **2** |
| `!interactive && description.is_empty()` | Usage: `description required (or --interactive)` → exit **2** |
| `interactive && !is_stdin_tty()` | Usage: `design --interactive requires a TTY` → exit **2** |
| desc trim empty / oversize | InvalidInput → exit **4** |
| root None | InvalidInput → exit **4** |
| Io write | exit **5** |

### Interactive (en-US, single-line alpha)

1. `Title (empty = derive from description): `
2. `Description: `
