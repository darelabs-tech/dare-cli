## Contratos

### `merge_preserve(existing: &str, fresh: &str) -> CoreResult<String>`

1. Parse `fresh` → map `section_id → full_block` (BEGIN…END inclusive) para cada `ENRICHABLE`.
2. Se `existing` **não** contém `AGENT:BEGIN`:
   - Retornar `fresh` + appendix:

```markdown
## APPENDIX — Preserved previous content

<!-- dare:preserved -->
{existing}
```

3. Se `existing` tem markers: base = `existing`; para cada id em `ENRICHABLE` substituir bloco pelo de `fresh`; texto fora de markers intacto; marker ausente → inserir após heading da secção ou append.
4. BEGIN sem END → `CoreError::invalid_input("malformed AGENT markers in DARE/DESIGN.md")`.

### `apply_design(root: &ProjectRoot, input: &DesignInput) -> CoreResult<DesignReport>`

1. Ensure dir `DARE/` sob root.
2. Path relativo `DESIGN_REL` apenas (jail via `dare-core`).
3. Missing → `action="created"`, write `render_canonical`, `preservedRegions=0`.
4. Exists → read ≤ `DESIGN_READ_CAP`, `merge_preserve`, `action="updated"`, contar `preservedRegions`.
5. `atomic_write`; `markerCount=4`; `ok=true`; `path="DARE/DESIGN.md"`.

### Edge cases

| Caso | Resultado |
|------|-----------|
| existing vazio | created / fresh |
| notes fora de marker | sobrevivem |
| oversize read | InvalidInput ou Io conforme dare-core |
