# Task mp048-004: hooks run_hooks + SafeCommand spawn

> **Complexity:** HIGH · **Depends on:** mp048-003 · **Rank:** 2

## Objetivo

Implementar `run_hooks` com trust gate, idempotência e spawn argv-only via `current_exe` (BLUEPRINT-048 §5.2–5.3 / §0.3).

## Arquivos

| Ação | Caminho |

## MUST

- `!enabled` → `Err(usage(MSG_HOOKS_DISABLED))`
- `!(trusted || trust_flag)` → `Err(usage(MSG_HOOKS_TRUST))`; **zero** spawn
- `SafeCommand`: program = `std::env::current_exe()`, args = `action_argv`, timeout 120s
- Marker hit → `status: skipped`, `reason: idempotent`
- Spawn exit 0 → write marker; ≠0 → `failed`, sem marker
- Retorna `Ok(HooksRunReport)` se trust/defs ok (CLI mapeia failed→exit 1)
- `ProcessRunner` injectável para testes
