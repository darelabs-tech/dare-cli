# Task mp008-003: Fixtures golden round-trip

## Objetivo

Garantir que configs legadas / com extras / `enabled:false` carregam sem perda (O-02, RF-17).

## Descrição

Criar `crates/dare-config/tests/fixtures_roundtrip.rs`.

### Fixtures (já no repo)

| Ficheiro | Asserts mínimos |
|----------|-----------------|
| `legacy.config.json` | `ide` presente; `guard.enabled == Some(false)`; unknown/`customExtension` em `extra` |
| `with_extras.config.json` | chaves unknown em `extra` após load |
| `enabled_false.config.json` | `validate(&cfg)` Ok |

### Fluxo por fixture

1. `tempfile::tempdir`
2. Copiar bytes da fixture → `dare.config.json`
3. `ProjectRoot::new` + `SafeRelativePath::new("dare.config.json")`
4. `load_dare_config` **ou** `load_effective(..., EnvOverrides::default(), CliOverrides::default())`
5. `validate` Ok
6. `merge_layers(&default_config(), Some(&cfg), &EnvOverrides::default(), &CliOverrides::default())` preserva extras do file (B3)

### Edge cases

| Caso | Esperado |
|------|----------|
| Fixture missing no path de teste | falha de teste clara (path relativo a `CARGO_MANIFEST_DIR`) |
| JSON malformado | fora deste teste (já em `load.rs`) |
