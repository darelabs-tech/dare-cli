## MUST

```rust
pub async fn serve(
    mode: AppMode,
    cfg: ServerConfig,
    shutdown: impl Future<Output = ()> + Send + 'static,
) -> CoreResult<()>;

pub fn open_browser(url: &str, runner: &dyn ProcessRunner) -> CoreResult<()>;
```

- URL: `^https?://(127\.0\.0\.1|localhost)(:\d+)?(/.*)?$`
- Win: `cmd.exe /C start "" <url>`; macOS `open`; Linux `xdg-open`
- Falha browser → warn, **não** derruba serve
- Log startup: `token=set|generated` (valor só se `DARE_MCP_LOG_TOKEN=1`)
