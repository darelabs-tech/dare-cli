## Locate (algoritmo)

1. `q = opts.query.trim()`; se vazio → `InvalidInput` com `"query must not be empty"`.
2. Seeds = nós onde `node_matches_keyword`; se vazio → `Ok(vec![])`.
3. BFS a partir das seeds; score = `1.0 * opts.decay.powi(hop as i32)`; manter **max** por id.
4. Ordenar score DESC, id ASC; aplicar `limit`.
5. Caps: hops ≤5, fanout ≤200, limit ≤100 (usar constantes de `search`).

## Owners

1. Se `get_node(seed)` é None → `InvalidInput` `"unknown node"`.
2. Se `metadata["owner"]` é string não vazia → incluir o valor trimado.
3. Incluir sources de edges `Contains` com `target_id == seed`.
4. Dedup + sort ASC.
