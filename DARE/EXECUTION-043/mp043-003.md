## Assinaturas (MUST)

```rust
#[derive(Debug, Clone)]
pub struct DriftOptions {
    pub threshold: u32, // default 1
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct DriftReport {
    pub orphan_requirements: Vec<String>,
    pub orphan_code: Vec<String>,
    pub stale: Vec<String>,
    pub violations: u32,
    pub threshold: u32,
}

pub fn drift(g: &dyn KnowledgeGraph, opts: &DriftOptions) -> CoreResult<DriftReport>;
pub fn drift_exceeds_threshold(report: &DriftReport) -> bool;
```

## Regras de classificação

| id lista | Quando |
|----------|--------|
| `orphan_requirements` | `NodeType::Requirement` sem edge outbound `implements` |
| `orphan_code` | `File` ou `CodeSymbol` sem edge inbound `implements` |
| `stale` | `metadata["stale"]` é JSON `true` ou string `"true"` (ASCII case-insensitive) |

- Cada lista: dedup + sort ASC.
- `violations = orphan_requirements.len() + orphan_code.len() + stale.len()` (como u32).
- `drift_exceeds_threshold`: se `threshold == 0` → `violations > 0`; senão → `violations >= threshold`.
- Domínio sempre retorna `Ok(report)` quando o grafo é legível — **exit 7 é só no CLI** (mp043-005).
