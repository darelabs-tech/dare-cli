## Impact

1. Validar cada seed existe; senão `InvalidInput`.
2. BFS Out apenas nas edge types: `depends_on`, `uses`, `contains`, `affects`, `implements`.
3. Excluir seeds do resultado; ordenar ASC; aplicar `limit`.
4. Caps: hops ≤5, fanout ≤200.

## Trace

1. `from` e `to` devem existir; senão `InvalidInput`.
2. Todos os caminhos de comprimento mínimo dentro de `max_hops`.
3. Ordenar: `path.len` ASC, depois join lex dos ids.
4. Se nenhum caminho → `Ok(vec![])`.
