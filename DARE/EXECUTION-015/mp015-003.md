> **Complexidade:** MED  
> **Depends on:** mp015-002

## Objetivo

Jobs `checksums-sbom` e `publish` produzem meta canónica e Release prerelease só em tag (com dry_run gate).

## Arquivos

| Ação | Caminho |
|------|---------|
| MODIFICAR | `.github/workflows/release.yml` |

## SHA256SUMS

- Só `*.tar.gz` / `*.zip`
- Linha: `<hex>  <filename>` (dois espaços)
- Sort por filename
- LF UTF-8

## SBOM.spdx.json (mínimo)

Campos: `spdxVersion=SPDX-2.3`, `dataLicense=CC0-1.0`, `SPDXID=SPDXRef-DOCUMENT`, `name=dare-cli-${VERSION}`, `documentNamespace=https://github.com/dewtech/dare-cli/spdx/${VERSION}`, `creationInfo`, `packages[0]` name=`dare` SPDXID=`SPDXRef-Package-dare` `filesAnalyzed=false` `versionInfo=${VERSION}`.

## Cosign

- Tentar `sign-blob` (OIDC ou `COSIGN_KEY`)
- Se falhar/indisponível: ficheiro `.sig` com texto começando `signing skipped`
- Job **não** falha por assinatura

## Publish

```text
if: startsWith(github.ref, 'refs/tags/') &&
    (github.event_name != 'workflow_dispatch' || inputs.dry_run == false)
```

- `softprops/action-gh-release@v2.2.1`
- `prerelease: true`, `files: dist/**`, `generate_release_notes: true`
- Meta artifact inclui: SHA256SUMS, SHA256SUMS.sig, SBOM.spdx.json, install.sh, install.ps1

## Validation Gates

- [ ] Jobs + condição publish presentes
- [ ] SBOM campos no script
- [ ] Sem secrets hardcoded; permissions `contents: write` + `id-token: write`
- [ ] Sem git commit / sem tags

## Definition of Done (ANTI-STUB)

- [ ] Formatos reais (não comentário “TODO SBOM”)
- [ ] Cosign soft-fail implementado
- [ ] Sem git commit
