# Task mp015-004: Installers install.sh + install.ps1

> **Complexidade:** MED  
> **Depends on:** —  
> **Fase:** 4 — Installers (BLUEPRINT-015 §5.3–5.4)

## Objetivo

Installers Unix/Windows cumprem env, detect target, checksum (sh MUST / ps1 warn), instalação idempotente e `--version`.

## Arquivos

| Ação | Caminho |
|------|---------|
| MODIFICAR | `installers/install.sh` |
| MODIFICAR | `installers/install.ps1` |

## Env (ambos)

| Var | Regra |
|-----|-------|
| `DARE_VERSION` \| `DARE_LOCAL_ARCHIVE` | Um obrigatório |
| `DARE_REPO` | default `dewtech/dare-cli` |
| `DARE_INSTALL_BASE` | default releases latest/download |
| `DARE_PREFIX` | Unix `$HOME/.local`; Win `%LOCALAPPDATA%\dare` |

## install.sh

1. `detect_target` → 4 triples Unix  
2. Ambos env vazios → **exit 2**  
3. Remoto: curl + `sha256sum -c --ignore-missing` (fail mismatch)  
4. `install -m 755` → `$PREFIX/bin/dare`  
5. `"$BIN" --version`  
6. **Proibido:** `eval`

## install.ps1

1. Só `x86_64-pc-windows-msvc`; arm64 throw  
2. Sem env → throw  
3. Checksum mismatch → throw; sums fail → Warning  
4. `dare.exe` → `$BinDir`; `--version`

## Edge cases a cobrir no script

- unsupported OS/arch (sh exit 1)
- reinstall sobrescreve
- LOCAL sem checksum remoto

## Validation Gates

- [ ] Grep: `DARE_LOCAL_ARCHIVE`, exit/`throw`, `--version`
- [ ] Sem `eval` em install.sh
- [ ] Sem git commit
