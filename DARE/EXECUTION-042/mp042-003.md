## Algoritmo vector_rank (MUST)

1. Cap query ≤ 8192; passages ≤ 2048  
2. Embed query + passages; dim ≠ 384 → Internal  
3. Cosine; sort score DESC, id ASC → `Vec<String>` ids  

Candidatos: union keyword∪BFS, sort id ASC, take **512**.

## Fallback (MUST)

Qualquer falha (sem cache, embed err, feature off) → 2-list 041 + warning prefix `semantic unavailable:` + **Ok** (não Err na query).

`no_semantic=true` → nunca chama ensure/embed.
