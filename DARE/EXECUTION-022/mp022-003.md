### `UpdateApplyReport` (camelCase)

`schemaVersion=1`, `mode="update"`, `cliVersion`, `projectRoot`, `backupRoot`, `target`, `force`, `yes`, `kept`, `created`, `replaced`, `skipped`, `backedUp`, `migrated`, `warnings`, `rolledBack=false` no Ok.

### Algoritmo (sem migrate — mp022-004)

1. Collect customized paths; `batch_replace` via `AskFn` se interactive
2. Para cada `plan.items`: `resolve_action` → Keep (warnings se customized) ou Replace
3. Replace: `canonical_bytes_for` → session_backup se exists → `atomic_write` → journal created/replaced
4. On Err: `rollback_session` → return Err
5. Sort path lists; return Ok

**Config migrate:** defer mp022-004 — se item `dare.config.json`, pode skip com nota **ou** write canonical only; migrate steps MUST em 004.

Human MUST terminar com linha `mode: update`.
