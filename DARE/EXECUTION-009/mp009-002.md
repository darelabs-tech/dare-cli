# Task mp009-002: Harden path + materialize errors

## Objetivo

Validar paths do manifest e eliminar unwraps inseguros em materialize (RS-01).

## Descrição

### Assinatura

```rust
pub fn assert_safe_asset_path(path: &str) -> CoreResult<()>;
```

### Regras

1. `path` non-empty  
2. Não começa com `/` ou `\`  
3. Nenhum segmento `..` (split por `/`)  
4. Não contém `\`  

### Integração

- `verify_embedded_assets`: chamar para **cada** entry (incl. external)  
- `materialize_to`: chamar antes de `SafeRelativePath::new` / write  
- Encoding UTF-8 do manifest: `Err(Config)` tipado — sem `unwrap_or("")` / `.expect`

### Edge cases

| Input | Resultado |
|-------|-----------|
| `templates/../etc/passwd` | Err |
| `foo\bar` | Err |
| `/abs` | Err |
| `templates/DESIGN-template.md` | Ok |

## Arquivos

- `crates/dare-assets/src/verify.rs`
- `crates/dare-assets/src/materialize.rs`
- `crates/dare-assets/src/lib.rs` (export se público)
