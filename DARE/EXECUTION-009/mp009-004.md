# Task mp009-004: Scripts regen + sync espelho

## Objetivo

Ferramentas para regenerar SHA-256 e sincronizar espelho `templates/` (RF-14, T-02).

## Descrição

### `scripts/regen-assets-manifest.py`

- Input: `assets/manifest.yml`
- Para cada asset `kind != external`: hash SHA-256 do ficheiro `assets/{path}`
- Output: mesmo YAML com `sha256` atualizado (hex lowercase)
- Preservar `id`, `path`, `kind`, ordem

### `scripts/sync-templates-from-assets.ps1`

```powershell
Copy-Item -Path "assets/templates/*" -Destination "templates/" -Force
```

Comentário no topo: correr após editar `assets/templates`.
